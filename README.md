# Luper - Windows Optimizer

Luper, Windows işletim sisteminiz için tasarlanmış profesyonel bir optimizasyon aracıdır.
İşletim sisteminizin performansını maksimize eder, gecikmeleri düşürür ve en akıcı deneyimi sağlamak için gereksiz servisleri devre dışı bırakır.

## Özellikler

- **Ağ & İnternet Optimizasyonu:** Gecikmeyi azaltır, ping değerini stabilize eder.
- **CPU & Depolama İyileştirmeleri:** İşlemci çekirdeklerini en verimli şekilde kullanır, SSD ömrünü uzatır.
- **Fare & Klavye İnce Ayarları:** Input lag değerini en aza indirerek 1:1 piksel doğruluğu sağlar.
- **Gizlilik & Güvenlik:** İstenmeyen telemetri servislerini ve arka plan izlemelerini durdurur.
- **Modern Arayüz:** Akıcı, koyu temalı ve kullanımı son derece kolay arayüz.

## Kurulum ve Çalıştırma

Geliştirme ortamını ayağa kaldırmak için:

```bash
npm install
npm run dev
```

Projeyi derlemek (Electron tabanlı Windows uygulaması için) için:

```bash
npm run build
npm run dist
```

## Teknolojiler

- **Arayüz:** React, TypeScript, Tailwind CSS, Framer Motion
- **Çekirdek:** Node.js, Electron (Nihai derleme ortamı)
- **Veri & Meta:** Firebase (Kategori güncellemeleri ve değişiklik kayıtları)
